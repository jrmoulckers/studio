# Agent Instructions — JRM Studio

JRM Studio follows a standard **principles practice**, organized as a tree by realm in
[`principles/`](principles/). These principles are **binding practice** for every
contributor and every AI agent working in this repo.

## What every agent must do

1. **Follow the principles.** Before working in a realm, read that realm's file in
   `principles/` and follow its principle tree. Cross-cutting work follows every realm it
   touches.
2. **Use your aligned realm.** Each specialist agent owns a realm — see the realm → agent
   map in [`principles/AGENTS.md`](principles/AGENTS.md). Treat your realm's principles as
   the source of truth.
3. **Cite the principle.** When a decision is driven by a principle, name it.
4. **Propose, don't improvise.** If a principle is missing or unclear, draft an addition in
   the realm file and flag it for the owner instead of acting on an unwritten rule.
5. **Keep the tree honest.** Principles must stay short, testable, and specific.

## Realms

See [`principles/README.md`](principles/README.md) for the full realm tree and
[`principles/AGENTS.md`](principles/AGENTS.md) for the realm → agent alignment.
