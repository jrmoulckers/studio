# @jrm/tailwind-preset

A ready-to-use [Tailwind CSS](https://tailwindcss.com) preset for **JRM Studio**.

The preset is **generated by [`@jrm/tokens`](../tokens)**, and this package is a thin
re-export that adds one thing a generated data file cannot carry: the `tailwindcss-animate`
plugin instance. Keeping the shell in the generated file — rather than here — is deliberate:
product repositories receive `dist/` as a _copied directory_, not an installed package, so
anything defined only in this wrapper would be unreachable downstream. There is therefore
exactly one definition of the shell, and vendored and installed consumers cannot drift.

The generated preset provides:

- **class + attribute dark mode** — `darkMode: ["class", '[data-theme="dark"]']`, matching the
  `@jrm/tokens` CSS variable scheme.
- **container** centered at `1rem` padding, `760px` max (the score-king content-max token).
- **radius aliases** — `DEFAULT` → `--radius-md`, `full` → `--radius-pill`, on top of the
  token `borderRadius` scale.
- **token-backed focus rings** — `ringWidth`/`ringOffsetWidth` default to `--focus-ring-width`
  and `--focus-ring-offset`, so high-contrast and cognitive modes widen every ring by
  redefining one variable.
- **safe-area spacing** — `safe-t`/`safe-r`/`safe-b`/`safe-l` → `env(safe-area-inset-*)`.
- **structural scales** — `zIndex` from `--layer-*`, elevation `boxShadow`, `opacity`, and
  `minHeight`/`minWidth` from `--target-*`.
- **animations** — `fade-in`, `pop-in`.

Because the colors/spacing/radius/shadow/typography all resolve to CSS variables, a runtime
theme or mode swap (changing `data-theme`) re-flows every utility with **no rebuild**.

> **Current availability:** this wrapper is workspace-internal. It is not published or
> synced to product repositories — but it no longer needs to be. Products receive the same
> preset object through the generated token dist and consume it by vendored path; see
> [`@jrm/tokens` product-repository usage](../tokens/README.md#product-repositories-synced-dist).
> Add `tailwindcss-animate` directly if you use those utilities.

## Usage

Import the CSS variables once (from `@jrm/tokens`) and apply the preset:

```js
// tailwind.config.js (or .cjs)
module.exports = {
  presets: [require('@jrm/tailwind-preset')],
  content: ['./src/**/*.{js,ts,jsx,tsx,svelte,mdx,html}'],
};
```

```css
/* app entry CSS */
@import '@jrm/tokens/css'; /* defines the --… variables the preset references */
@tailwind base;
@tailwind components;
@tailwind utilities;
```

Now utilities like `bg-background`, `text-foreground`, `bg-primary`, `text-accent-ink`,
`rounded-md`, `shadow-lift`, `shadow-raised`, `z-dialog`, `min-h-min`, `pb-safe-b`,
`text-player-3`, and `animate-pop-in` are available and theme-aware.

## Requires

- `tailwindcss` (peer, `>=3`)
- `@jrm/tokens` built first (`pnpm --filter @jrm/tokens build`) so `@jrm/tokens/tailwind`
  exists — the workspace `build` pipeline handles this ordering automatically.
